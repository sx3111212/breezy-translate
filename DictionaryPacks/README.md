# Optional expanded English–Chinese pack

Import ecdict-full-en-zh.json.gz in Language Helper → Settings → General settings → Offline dictionaries.

399,980 single-word entries; about 9.5 MiB. Distributed separately to keep app output small.
Source: https://github.com/skywind3000/ECDICT (MIT). Retain ECDICT-LICENSE.txt.

To distribute, attach the .json.gz file and license to a GitHub Release. The app accepts its HTTPS direct file link or a local import, not the release HTML page URL.
